READY-TO-UPLOAD WEBSITE FILES
The website is built and the folders are clickable. The listed activity/project entries are clearly marked placeholders, not actual school submissions. Add your own work before submitting the portfolio if your teacher requires the actual outputs.

HOW TO PUBLISH WITH GITHUB PAGES (FREE)
1. Download and extract this ZIP file.
2. Sign in to https://github.com or create an account.
3. Create a new PUBLIC repository. Suggested name: manahan-jay-portfolio
4. Upload the contents of this extracted folder (index.html, style.css, script.js, README.txt, and the files folder). Upload the files themselves, not the ZIP.
5. Open the repository Settings.
6. Select Pages from the left menu.
7. Under Build and deployment, select "Deploy from a branch".
8. Select branch "main" and folder "/ (root)", then click Save.
9. Wait a few minutes. Your site URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/manahan-jay-portfolio/

HOW TO ADD YOUR SCHOOL FILES LATER
1. In GitHub, open the repository and choose Add file > Upload files.
2. Upload your PDF, image, PowerPoint, or video into the matching folder under files/.
3. To make a file appear in the clickable portfolio, open script.js and add an entry to the correct folder's files array:
   { name: "My Activity 1", kind: "pdf", url: "files/activity/activity-1.pdf" }
   Supported kinds: pdf, image, video, note.
4. Commit the changes. GitHub Pages will update the website automatically.
